MultiCS r1000 v1.10.9 - by Sharillas@2026
==========================================

Pacote de release (ultima build, bugs corrigidos)

CONTEM:
  bin/multics.x64        binario 64-bit (static musl - corre em qualquer
                         Debian/Ubuntu x86_64 sem dependencias)
  bin/multics.x32        binario 32-bit
  configs/               multics.cfg, profiles.cfg, CSS, ip2country.csv, etc.
  install.sh             instalador (configs para /var/etc, binarios para /opt/multics)

INSTALACAO NA VPS (Debian/Ubuntu, como root):
  cd /tmp && tar xzf multics-r1000-v1.10.9.tar.gz && cd multics-r1000
  bash install.sh /opt/multics
  /opt/multics/multics.x64 -b -C /var/etc/multics.cfg

WEB UI:  http://IP:5500   (user: admin / pass: admin - mudar no multics.cfg)
         Depois do login vai para /dashboard
