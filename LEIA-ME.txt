MultiCS r1000 v1.23 - by Sharillas@2026
==========================================

Pacote de release (última build estável)

CONTÉM:
  bin/multics.x64        binário 64-bit (estático musl - corre em qualquer
                         Debian/Ubuntu x86_64 sem dependências)
  bin/multics.x32        binário 32-bit
  bin/tools_update_*.py  ferramentas (Update Channel Info + Update SoftCam.Key
                         + Update Ip2Country diário)
  configs/               multics.cfg, profiles.cfg, CSS, ip2country.csv, etc.
  install.sh             instalador (configs para /var/etc, binários para /opt/multics,
                         serviço systemd como root, chmod 666 nas configs)

INSTALAÇÃO NA VPS (Debian/Ubuntu, como root):
  cd /tmp && tar xzf multics-r1000-v1.23.tar.gz && cd multics-r1000
  bash install.sh /opt/multics
  systemctl start multics

WEB UI:  http://IP:5500   (user: admin / pass: admin - mudar no multics.cfg)
         Depois do login vai para /dashboard

Portas: HTTP 5500, Telnet 5600, CCcam 16000, CCcam3 16001, MGcamd 21000,
        camd35 7502, cs378x 8600, cache 5599, perfis newcamd 15000+

PRINCIPAIS CARACTERÍSTICAS (v1.23):
  - GUI completa (dark/light, responsiva em telemóvel): Dashboard, Servers,
    Cache, CacheEX, Newcamd, Mgcamd, CCcam, Cs358x/Camd35, Profiles,
    Packages, Softcam, Configs
  - Packages: dashboard por satélite (30W/13E/19.2E) - package, CAID:Ident,
    perfil, Ecm OK, readers
  - Test Channel: canal de teste configurável pela GUI (sessão ou multics.cfg)
  - Servers: coluna Cards com ident a 6 dígitos + nomes (MEO ID, NOS ID,
    Canal+ Polónia...), cores de estado, stats de ECM Dedup
  - DEDUP de ECMs: 1 pedido único ao reader por ECM em voo
  - NOK cache por reader+canal (~8s): menos tráfego NOK em zappings
  - Proteções: SKIPCWC, CWC, NAGRA protection, DCW MINTIME/CYCLE_CHECK,
    anti-fake XOR 0xF0 + nano e0, BUILD LITE
  - Login guard anti brute-force: 5 falhas -> bloqueio 30s por IP
    (configurável em HTTP LOGIN MAXFAIL/LOCKTIME)
  - Sessões persistentes + botão "Terminar todas as sessões" + invalidação
    automática ao mudar a password; cookie HttpOnly + SameSite=Lax
  - Upload Configs com validação (comenta linhas com erro, defaults,
    rollback .bak) - nunca crasha
  - Editor AJAX de todos os ficheiros com feedback "Guardado"
  - Softcam: upload SoftCam.Key, Update SoftCam.Key remoto, Reload Keys
  - Update Channel Info (KingOfSat) pela GUI
  - ip2country diário (base iplocate) com bandeiras na GUI -
    tools/update_ip2country.py (sugestão: cron diário)
  - Log em ficheiro com rotação (-f no serviço) + crash-report com core dumps
  - Identificações CAID oficiais dos 3 satélites (30W/13E/19.2E) em
    profiles/providers/channelinfo
  - Assinaturas de protocolo na info server (Newcamd v6.06, Mgcamd v1.46, ...)
  - Download Log na página Debug (500 entradas)
  - Fixes anteriores: SKIPCWC, CWC, NAGRA, Health, Fallback, Timing,
    Emulator BISS, SIG_HANDLER, CSCACHE, restart fiável, dcwtimeout,
    retry recvtime, spin dashboard, nocheck por reader
