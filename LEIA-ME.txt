Pacote de release (última build estável)

CONTÉM:
  bin/multics.x64        binário 64-bit (estático musl - corre em qualquer
                         Debian/Ubuntu x86_64 sem dependências)
  bin/multics.x32        binário 32-bit
  bin/tools_update_*.py  ferramentas (Update Channel Info + Update SoftCam.Key
                         + Update Ip2Country diário)
  configs/               multics.cfg, profiles.cfg, CSS, ip2country.csv, etc.
  install.sh             instalador (SEM GIT: copia só binários + configs para
                         a VPS, cria serviço systemd, e no fim mostra um GUIA
                         completo do projeto para quem instala)

INSTALAÇÃO NA VPS (Debian/Ubuntu, como root - SEM git clone):
  cd /tmp && tar xzf multics-r1000-v1.26.tar.gz && cd multics-r1000
  bash install.sh /opt/multics
  systemctl start multics

  (o install.sh no fim explica ONDE ESTÃO os ficheiros de config,
   COMO funciona o projeto e os PRIMEIROS PASSOS - para leigos)

WEB UI:  http://IP:5500   (user: admin / pass: admin - mudar no multics.cfg)
         Depois do login vai para /dashboard

Portas: HTTP 5500, Telnet 5600, CCcam 16000, CCcam3 16001, MGcamd 21000,
        camd35 7502, cs378x 8600, cache 5599, perfis newcamd 15000+

NOVO v1.25 (pacote anti-"cartões marcados" - análise do MultiCS r120):
  - DCW FILTER (CWPK): blacklist de CWs de cartões marcados (35 valores);
    modo AUTO = desligado por defeito, ativa-se SOZINHO no 1º hit e passa
    a bloquear (sem ninguém ver o log); modos LOGONLY e DROP manuais;
    regras EXACT/MASK/ALLEQUAL
  - ECM FILTER (rule engine): PREFIX / LEN multi / BYTE <pos> INMASK <mask64>
    (a validação iCAM é config: BYTE 21 INMASK 1300010012)
  - FAILBAN: ban automático de IPs por eventos maus, por protocolo
  - ANTICASCADE: anti-reshare por zapping excessivo
  - ECMRATELIMIT: proteção do cartão físico (SIDTIME/MAXECM)
  - DCW CAK7 (CAK7 Merlin): transformação iCAM da CW (Sky DE 098D / MEO / NOS) com
    perfil [SkyDE-098D] de exemplo comentado
  - Estado de tudo visível na GUI (página do perfil + botão DBG)

NOVO v1.24:
  - SILENT NOK adiado (2.5s): responde antes do timeout da box do cliente -
    elimina reconexões e storms de retries (todos os protocolos)
